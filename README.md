# 🌕 Tithi API

Быстрое и независимое REST API для вычисления ключевых элементов ведической астрологии (Панчанги). Проект работает на базе **Cloudflare Workers** и выполняет все астрономические вычисления "на лету" без использования сторонних библиотек.

## 🚀 Особенности

* **Полная независимость:** Все расчеты лунных и солнечных долгот (Julian Date) реализованы внутри кода.
* **Высокая скорость:** Работает на edge-серверах Cloudflare.
* **Простота использования:** Принимает всего три GET-параметра.
* **Подробный ответ:** Возвращает Титхи, Накшатру (с атрибутами), Йогу, Карану, Масу, Раши и Риту.

## 🔗 Базовый URL

`https://tithi-api.ewenloyteam.workers.dev/`

## 🛠 Установка и запуск

Проект готов к деплою в Cloudflare Workers.

1. Склонируйте репозиторий.
2. Установите Wrangler CLI.
3. Запустите команду `wrangler dev` для локального тестирования.
4. Выполните `wrangler deploy` для публикации.

## 📖 API Документация

### Эндпоинт
`GET /`

### Параметры запроса

| Параметр | Обязательный | Формат | Пример | Описание |
|---|---|---|---|---|
| `date` | Да | `YYYY-MM-DD` | `2023-10-24` | Локальная дата для расчета. |
| `time` | Да | `HH:MM` | `15:30` | Локальное время. |
| `timezone` | Да | `+/-HH:MM` | `+05:30` | Часовой пояс (смещение от UTC). |

### Пример запроса

```bash
curl -X GET "[https://tithi-api.ewenloyteam.workers.dev/?date=2023-10-24&time=15:30&timezone=+05:30](https://tithi-api.ewenloyteam.workers.dev/?date=2023-10-24&time=15:30&timezone=+05:30)"
